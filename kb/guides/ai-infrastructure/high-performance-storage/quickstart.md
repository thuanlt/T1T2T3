# Quickstart

## Sign up for an account​

  1. Go to https://id.fptcloud.com/ and select **Sign up**
  2. If the confirmation email doesn't appear in your Inbox, check your Junk email folders.
  3. Sign in to https://console.fptcloud.com/ for the Vietnam region and https://console.fptcloud.jp/ for the Japan region to begin using the service.

## For using HPS with Metal Cloud​

  1. **Create a Mount Point in the FPT Cloud Console** — Set up a new mount point with your preferred configuration. (This step applies only if your deployment is in the **Vietnam region**.)
  2. Build, install, and configure the client on your servers if you are using a **custom image** (based on OS Ubuntu).
  3. After deploying the server, create a **new mount point** in the operating system.
  4. Mount the **file system** to your GPU VMs using the provided endpoint.
  5. **Verify** that the mount is successful and the file system is accessible.

## For using HPS with a GPU Virtual Machine​

  1. Provide the subnet CIDR used by your GPU VMs to the **FPT Support Team**.
  2. Build, install, and configure the **storage client** on your GPU VMs.
  3. After deploying the server, create a **new mount point** in the operating system.
  4. Mount the **file system** to your GPU VMs using the provided endpoint.
  5. **Verify** that the mount is successful and the file system is accessible.
