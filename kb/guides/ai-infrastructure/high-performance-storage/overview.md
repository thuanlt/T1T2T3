# High-Performance Storage

## What is High-Performance Storage?​

**File Storage—High Performance (HPS)** is a fully managed service providing cost-efficient, high-performance, and scalable storage for GPU compute workloads. It supports demanding scenarios like AI/ML training, HPC, and video rendering, where multiple compute instances require simultaneous access to shared data with low latency and high throughput.

Powered by VAST Data and DDN Storage—leading high-performance file system technologies optimized for NVIDIA GPU clusters—HPS delivers exceptional performance, offering throughput of up to hundreds of gigabytes per second and tens of thousands of IOPS for the most data-intensive workloads.

## How Does It Work?​

Mount HPS to GPU Bare Metal and GPU Virtual Machine services via the compute network (subnet) for seamless integration with GPU workloads.

## Why High-Performance Storage?​

  * **Highly Performant and Scalable:** Achieve hundreds of GB/s throughput and thousands of IOPS for demanding workloads.
  * **Seamless S3 Integration:** Easily access and transfer data from other S3 buckets with S3 gateway support.
  * **Simple and Fully Managed:** Launch and manage HPS in a couple of hours, with no need for hardware provisioning or ongoing maintenance.
